CAMO/GrADS 13色カラーマップ見本

This section shows 13-color samples for set rgbmap NAME [start] [reverse]. / set rgbmap NAME [start] [reverse] 用の13色見本です。

set rgbmap viridis
set rgbmap RdBu_r
set rgbmap cividis 16 reverse
The _r suffix or reverse option reverses the color order. / _r または reverse で色順を反転します。
