What You Can Do with GrADS CAMO

GrADS CAMO is an unofficial downstream build based on GrADS 2.2.3. It aims to preserve familiar GrADS scripts while adding practical improvements for current systems, plotting, geographic annotation, colormaps, fonts, data export, and compatibility.

Group 1

Display & design

Improve the appearance and presentation of GrADS figures without changing the basic workflow: themes, palettes, fonts, vector/streamline visibility, panel layouts, and hardcopy export.

X series #1

Modern theme: update the appearance without rewriting normal GrADS scripts

A single theme controls several defaults that affect the first impression of a map: aspect ratio, grid/map presentation, the default palette, and the default 2-D display mode.

'sdfopen file.nc'
'set theme modern'
'd mag(ugrd_10mabovegr,vgrd_10mabovegr)'
'draw title Modern theme'
'gxprint figure.png'

The CAMO modern theme changes the latitude/longitude aspect factor from 1.2 to 1.0 and uses a lighter map/grid presentation. It selects cividis as the default rainbow palette; the CAMO startup defaults also use gxout shade2 for a 2-D grid and increase the default X/Y tick-label size from 0.11 to 0.15.

The traditional behavior is still available. set theme classic restores the classic theme, and ordinary GrADS display commands remain available. The intention is to add a useful modern preset, not to make old scripts obsolete.

X series #5

Select colormaps by name

Use familiar palette names, including reversed forms, instead of defining every RGB entry manually.

'set rgbmap RdBu'
'set rgbmap RdBu_r'
'set rgbmap RdBu reverse'

GrADS CAMO includes 13-color RGB tables sampled from Matplotlib built-in colormaps, covering perceptually uniform, sequential, diverging, cyclic, and common legacy-style choices. NAME_r and the reverse option both reverse the order.

The web-based colormap tool provides a visual browser and can generate GrADS color/level settings. The current interface is Japanese, but the generated GrADS commands are language independent.

X series #6

Choose installed system fonts by family name

Make GrADS figures fit more naturally beside figures from other plotting software.

'set fontfamily IPAexGothic'
'set fontfamily Helvetica'
'set fontfamily DejaVu Sans'

set fontfamily selects a font through Cairo/fontconfig. GrADS CAMO does not bundle font files; the requested family must be installed on the host system.

This is useful for papers, posters, and slides where typography across several plotting tools should be consistent while the rest of the GrADS workflow remains unchanged.

X series #7

vector2 / stream2: improve contrast over shaded fields

A second drawing pass keeps vectors and streamlines readable when the background changes from dark to light.

'set gxout vector2'
'd u;v'

'set gxout stream2'
'd u;v'

These modes retain the upstream GrADS vector/stream algorithms but draw a semi-transparent background-colored outline before the main vectors or streamlines. This reduces the usual problem of white or dark lines disappearing over parts of a shaded map.

The original vector and stream modes are unchanged, so the CAMO modes can be selected only where they help.

vector2 / stream2 details
X series #8

Simple multi-panel layouts

Create common 2×2, 2×3, and similar layouts without hand-calculating a separate plot area for every panel.

'set panels 2 2'
'set panel 1'
'd u'
'set panel 2'
'd v'
'set panel 3'
'd mag(u,v)'
'set panel 4'
'd hgt'
'set panels off'

set panels defines a simple row/column viewport layout, and set panel selects the destination panel. Traditional set parea and set vpage remain available when full manual control is needed.

The feature is intentionally modest, but it removes repetitive page-coordinate arithmetic from a task that appears constantly in climate and meteorological analysis.

Web extra

Compact PNG, transparent PNG, PDF, and SVG export

Use concise hardcopy commands for web graphics, overlays, scalable office-document figures, and print output.

'export figure.png'
'export figure.png transparent'
'export figure.png scale 2'
'export figure.png width 1600'
'export figure.pdf'
'export figure.svg'

export is a compact CAMO entry point to the hardcopy path, including transparent PNG and simple size/scale controls. SVG and PDF can be used where vector output is preferable.

gxprint remains the canonical upstream GrADS hardcopy command. The added command is meant to make common output cases shorter, not to replace the established mechanism.

Group 2

Geographic drawing

Add annotations using the coordinates scientists actually use: longitude, latitude, eastward/northward vectors, and physical distance on the globe.

X series #2

Draw geographic rectangles with georec / georecf

Specify the study domain in longitude and latitude instead of page x/y coordinates.

'set line 1 1 8'
'draw georec 95 5 145 35'
'draw georecf 105 10 135 32'

georecとrec、vector2とvector、exportとgxprintは、それぞれ別のコマンドとして利用できます。

Rectangle edges are interpolated before projection using the GrADS map-polygon machinery, so nonlinear projections are handled more naturally than simply connecting four already-projected corners.

Geographic rectangle implementationMap/projection reference
X series #3

Draw geographic circles with geocirc / geocircf

Place a marker at a station, cyclone center, or analysis point using lon/lat directly.

'set line 1 1 8'
'draw geocirc 130 30'
'draw geocircf 130 30'

Without a distance argument, geocirc is a fixed-size map annotation centered at the supplied geographic coordinate. geocircf is the filled form.

The purpose is simple: when the scientific description is “mark 130°E, 30°N”, the script can use those values directly rather than performing a separate world-to-page conversion.

Geographic circle details
X series #4

Draw projection-aware vectors at geographic locations

Specify a lon/lat point and eastward/northward vector components.

'set line 1 1 8'
'set arrscl 1.2 20'
'draw geovec 125 25 20 10'

draw geovec LON LAT U V treats U as eastward and V as northward. It converts that direction to the active map projection using a local projected derivative.

Vector length remains controlled by set arrscl, separating the direction transformation from magnitude scaling and avoiding unwanted location-dependent length changes on non-conformal maps.

Projection handling in geovec
X series #11

Draw geodesic circles using a radius in kilometers

Represent equal distance on the sphere rather than a circle that merely looks circular on the page.

'draw geocirc 130 30 500 km'
'draw geocirc 130 30 5500 km'
'draw geocircf 130 30 1200 km'

Adding km creates a 72-segment geodesic circle on a spherical Earth before the points are projected. This is useful for cyclone-centered analysis, observational influence radii, or any threshold defined by physical distance.

On Robinson and other nonlinear projections the result may not look circular on the page. That is expected: the geometry is defined on the globe first.

Group 3

Analysis, export & compatibility tools

Connect GrADS calculations to other environments, keep common OpenGrADS regridding scripts useful, and make CAMO-specific commands easier to discover.

X series #9

Export GrADS results directly to CSV or plain text with txtwrite

Use GrADS for data access and calculation, then hand a compact result to Python, R, Excel, gnuplot, or another tool.

'txtwrite -csv -header out.csv tmp'
'txtwrite -csv -header -undef -9999 out.csv tmp'

txtwrite [-csv] [-header] [-undef VALUE] FILE EXPR provides dependency-free text export for one- and two-dimensional grid expressions. The default is space-separated text; -csv selects comma-separated output.

Coordinate columns follow the varying dimensions: lon/lat grids can produce lon,lat,value, while a time series can produce time,value. Station data and higher-dimensional expression results are deliberately outside the scope of this first text writer.

X series #10

Limited compatibility for the widely used OpenGrADS-style re()

Keep older regridding scripts useful for common regular lon/lat cases.

'd re(u,2.0,2.0)'
'd re(u,4.0,4.0)'
'd re(u,10.0,10.0)'

The CAMO re() implementation is a limited compatibility wrapper around the GrADS 2.2.3 lterp() interpolation core. It supports common OpenGrADS-style destination-grid arguments and the bl/bilin, bs/bessel, ba/aave, and ma,FRACTION methods.

When no method is specified, it follows the OpenGrADS convention of area averaging for a coarser output grid and Bessel interpolation for a finer output grid. Vote interpolation and Gaussian-grid options are explicitly rejected pending separate numerical validation.

Platforms & compatibility

Keep GrADS 2.2.3 buildable and usable with current compilers, libraries, Linux distributions, and Apple Silicon macOS while preserving long-lived scripts.

X series #12

Keep GrADS 2.2.3 usable on current Linux and macOS systems

A large fraction of the work is invisible in screenshots: compilers, libraries, packaging, and reproducible builds.

camo26.2 passed build, installation, 12/12 batch suites and clean-runtime startup on AlmaLinux 8/9/10, Fedora 44, Debian 13 and Ubuntu 24.04/26.04. Linux is x86_64/amd64; EL10 requires x86-64-v3. Native Apple Silicon source/batch checks use MacPorts libraries; formal camo26.2 Port installation remains pending.

The downstream patches address issues exposed by current GCC versions, modern HDF5 APIs, Debian/Ubuntu serial-HDF5 layouts, current g2c/GRIB2 interfaces, UDUNITS2 include paths, libpng16, shapelib, and related system-library changes.

Core idea: keep long-lived GrADS workflows usable on contemporary systems with as little disruption as practical.

Web extra

System-library linkage, packaging, and compatibility patches

Move away from old private supplement-library assumptions and toward normal system packages and filesystem layouts.

The packaging work uses system libraries and FHS-style installation paths. Build requirements cover components such as Cairo, GD, NetCDF, HDF4/HDF5, GRIB2, GeoTIFF, shapefile, and X11 where enabled by the target package.

RPM disables DAP/GADAP. Debian/Ubuntu enable gridded OPeNDAP and disable GADAP. HDF4 is enabled on all seven Linux targets, including Ubuntu 24.04. Enabled interfaces do not certify independent HDF4/HDF5 fixtures or remote OPeNDAP access. Check grads -blc "q config" and the validation matrix.

Web extra

Preserve existing scripts and add CAMO syntax only where needed

New features coexist with ordinary GrADS commands instead of forcing a new scripting dialect.

'sdfopen file.nc'
'set lon 100 160'
'set lat 10 50'
'd tmp'
'gxprint figure.png'

Normal GrADS scripts such as the example above do not need to be rewritten into CAMO-specific syntax. Features such as set theme modern, set rgbmap, set fontfamily, or set gxout vector2 can be added selectively.
