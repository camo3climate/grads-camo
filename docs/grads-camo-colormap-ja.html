CAMO/GrADS カラーマップとカラーバー生成

CAMO版GrADSに実装した13色カラーマップの一覧と、陰影図・色凡例用のGrADSコマンドを生成するページです。

実装では Matplotlib 組み込みカラーマップを13色にサンプリングしています。set gxout shaded または grfill の前に set rgbmap を指定します。_r を付けるか reverse を指定すると色順を反転します。

コマンド・カラーバー生成

-15 15 3 のように範囲を入れると、-15から15まで interval 3 の clevs、ccols、ラベル、camo_cbarn.gs 呼び出しを生成します。-3 3 を白にするような中心白抜きも指定できます。

実装メモ

  

    
実装コマンド
set rgbmap NAME [start] [reverse] は、既定で色番号16から13色を rbcols に読み込みます。

    
レベル固定
図ごとに色の意味を揃えるには、自動レベルではなく set clevs と set ccols を併用します。

    
中心白抜き
生成器は白の色番号に set rgb を設定し、指定範囲に入る階級へその色番号を割り当てます。
